# PRD_002 — Embed de Bandcamp en la página de álbum

- **Estado**: aprobado por el usuario (pedido directo, 2026-10-08)
- **Depende de**: PRD_001 (bloques editoriales ya implementados)

## Contexto

La página `/album/inesperado-contratiempo` enlaza a Bandcamp pero no permite escuchar
in-situ. El usuario entrega el embed oficial de Bandcamp para incrustarlo en la web.

## Fuente de verdad

Embed literal aportado por el usuario (sin modificar):

```html
<iframe style="border: 0; width: 100%; height: 120px;" src="https://bandcamp.com/EmbeddedPlayer/album=1060409196/size=large/bgcol=ffffff/linkcol=0687f5/tracklist=false/artwork=small/transparent=true/" seamless><a href="https://lllit3.bandcamp.com/album/inesperado-contratiempo">Inesperado contratiempo by LLLIT</a></iframe>
```

## Alcance

1. **Data** (`src/data/albums.ts`): nuevo campo opcional `bandcampAlbumId: string` → `"1060409196"`.
2. **Componente** `src/components/album/BandcampEmbed.astro`:
   - Construye el `src` del iframe desde `bandcampAlbumId` + `bandcampUrl` (data-driven, cero hardcode de URLs en la plantilla).
   - Respeta literalmente los parámetros del usuario: `size=large/bgcol=ffffff/linkcol=0687f5/tracklist=false/artwork=small/transparent=true/`.
   - A11y mínimo (no visual): `title` en el iframe + `loading="lazy"`.
   - Fallback interno `<a>{album.title} by {album.artist}</a>` (mismo texto que el embed original).
3. **Página** (`src/pages/album/[slug].astro`): insertar el componente **justo después del Tracklist** (escuchar → ver → escuchar), antes de Créditos.
4. **Tests**: `tests/prd002-bandcamp-embed.test.js`.

## Fuera de alcance

- Animación GSAP del embed (entra estático; sin data-* de animación).
- Ajuste de colores `bgcol`/`linkcol` para tema oscuro (pendiente de confirmación visual del usuario).

## Criterios de aceptación

1. Iframe con `album=1060409196` y todos los parámetros del embed literal.
2. `title` presente en el iframe; fallback `<a>` apunta a `bandcampUrl`.
3. El componente se renderiza desde data (`bandcampAlbumId`), no con la URL hardcodeada.
4. `node --test tests/*.test.js` en verde.
