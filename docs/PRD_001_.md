# PRD_001 — Sección editorial + Linkhub para `/album/inesperado-contratiempo`

- **Estado:** borrador (pendiente aprobación del usuario)
- **Fuente de verdad:** `docs/EPK-Inesperado/EPK - Inesperado contratiempo, by LLLIT - 2026.md`
- **Página afectada:** `src/pages/album/[slug].astro` + `src/data/albums.ts`
- **Fecha:** 2026-10-08

## 1. Contexto

La página `/album/inesperado-contratiempo` existe y funciona (hero con cover, countdown, tracklist, créditos, CTAs, GSAP). El EPK contiene contenido que hoy no está en la página: focus tracks, prensa/reseñas 2026, linkhub completo de streaming y copy oficial. El álbum ya salió (02-10-2026, hoy es 08-10-2026), por lo que el countdown está vencido.

## 2. Objetivo

Añadir, **en la misma página y bajo el mismo aesthetic** (mono fonts, bordes 1–2px, amber accents, scanlines, GSAP + ScrollTrigger), tres bloques nuevos que se revelan con scroll de forma ordenada:

1. **Focus tracks** — editorial largo de "Umbral" y "Latencia resiDual".
2. **Press / Reviews 2026** — reseñas y quotes con links.
3. **Linkhub** — todos los enlaces de escucha/venta en un solo bloque.

## 3. Alcance

### 3.1 Data (`src/data/albums.ts`)

Ampliar la interfaz `Album` con campos opcionales (backwards-compatible; el único álbum existente es este):

```ts
focusTracks: Array<{
  num: string          // "03"
  name: string         // "Umbral"
  blurb: string        // texto editorial del EPK (EN)
}>
press: Array<{
  outlet: string       // "Sykonee"
  quote?: string       // cita textual si existe
  url: string
  date?: string        // "2026-10-02"
  kind: "review" | "feature" | "share"
}>
streamLinks: Array<{
  label: string        // "Spotify"
  url: string
  primary?: boolean    // Bandcamp queda como CTA principal
  note?: string        // "Desvío Sin Aviso (playlist)"
}>
```

Correcciones de data existente alineadas al EPK:

- `genres` → `["Downtempo", "Dub techno", "Ambient", "Experimental electronic", "Techno (minimal / deep)"]`
- `description` (ES) y `descriptionEn` (EN) → párrafo narrativo del EPK (§ líneas 19–21), no el copy corto actual.
- `credits` → reflejar el EPK exacto:
  - Escrito, producido y masterizado por — LLLIT
  - Diseño (TouchDesigner) — LLLIT
  - Collage — Camola Bravo
  - Voz — Camila Bravo
  - Voz adicional — Groovidub
  - Diseño gráfico de tapa — Camila Bravo *(si el usuario confirma; ver §6)*
- `bandcampUrl` → URL exacta del álbum (`https://lllit3.bandcamp.com/album/inesperado-contratiempo`), no la home.
- `youtubeUrl` → link de la playlist/álbum del EPK si aplica (ver §6).
- **BPMs:** se mantienen como están (no vienen en el EPK). Fuera de alcance cambiarlos.
- **`previewUrl`:** sigue vacío. Fuera de alcance (no hay archivos de audio en el repo).

### 3.2 UI (`src/pages/album/[slug].astro`)

Insertar después del bloque actual de Redes y antes de "Volver a LLLIT", en este orden de scroll:

**A. Focus tracks** (`data-focus-section`)
- Header de sección en estilo `/// FOCUS TRACKS` (mono, uppercase, tracking amplio), consistente con el header actual de Tracklist.
- Dos entradas editoriales, una por track:
  - Fila con número + nombre del track (monospace, estilo del tracklist actual).
  - Párrafo del EPK con tipografía body (`text-sm`/`text-white/50`), máximo ~2–3 renglones en desktop.
  - Divider `border-white/[0.06]` idéntico al del tracklist.

**B. Press / Reviews 2026** (`data-press-section`)
- Header `/// PRESS — 2026`.
- Lista de items: outlet (mono, amber en hover) + cita (body, itálica o `text-white/50`) + link `target="_blank" rel="noopener noreferrer"`.
- Items con quote destacada (Parkett Channel, Doozy, Hominiscanidae) se muestran como mini pullquote; los que solo son links (Sykonee, 909Originals, Choonreview, MixCult) se muestran como fila compacta.
- Estética: grid 1-col en mobile, 2-col en desktop, separadores `1px` como el grid de créditos.

**C. Linkhub** (`data-linkhub`)
- Bloque centrado o full-width con el mismo treatment que el sticker/CTA: bordes `border-white/15`, fondo `bg-white/[0.02]`, mono labels uppercase.
- Botones en este orden:
  1. **Bandcamp** — primario, estilo `bg-[#fde047] border-2 border-[#fde047]` (el CTA actual, conservar la estética exacta).
  2. Spotify, Apple Music, YouTube, Download (dlcm.app) — secundarios, estilo del botón "¿Código promocional?" actual.
  3. Row de redes (IG/YouTube/SoundCloud) — se **mueven al linkhub** y se eliminan del bloque actual para no duplicar.
- El CTA actual de "/redeem" se conserva, integrado como último item secundario del linkhub (o se mantiene donde está — decisión visual en implementación, mismo estilo).

### 3.3 Countdown vencido

- Hoy muestra `out now` (rama del `if (diff <= 0)`), pero el bloque dice "Out in" y el CSS sigue de countdown.
- Cambio mínimo: cuando `diff <= 0`, el label "Out in" pasa a "Out now — stream / buy" y el valor se reemplaza por un link corto a Spotify o Bandcamp. Sin rediseño del bloque.

### 3.4 Animaciones (GSAP + ScrollTrigger)

Siguiendo la coreografía existente (`gsap.context` + `mm.add("(prefers-reduced-motion: no-preference)")`):

- Cada bloque nuevo entra con `gsap.from` disparado por `ScrollTrigger: { trigger: <bloque>, start: "top 80%" }`:
  - Header de sección: `y: 24, autoAlpha: 0, duration: 0.6, ease: "power3.out"`.
  - Items hijos: `stagger: 0.08`, `y: 16 → 0`, `autoAlpha: 0`, `duration: 0.45`, `ease: "power2.out"` (igual que `[data-track]` actual).
- **Onda ordenada:** los bloques comparten un eje vertical; al scrollear se revelan en el orden A → B → C naturalmente por su posición (no hace falta timeline encadenada entre secciones; cada una se auto-dispara).
- Linkhub: los botones entran con `stagger 0.06` + `scale: 0.96 → 1`.
- `prefers-reduced-motion: reduce` → todo estático (estado final visible, sin `from`).
- No usar `will-change` ni layout properties; solo `transform` + `opacity` (regla performance del repo).

## 5. Criterios de aceptación

1. `pnpm build` (usuario, Windows) compila sin errores de TS.
2. `node --test tests/*.test.js` (agente, WSL) pasa.
3. Tests nuevos en `tests/` que verifiquen:
   - `albums.ts` exporta `focusTracks`, `press`, `streamLinks` para `inesperado-contratiempo`.
   - Todos los `url` de `streamLinks`/`press` son `https://` válidos (regex).
   - El build output de la página contiene los `data-focus-section`, `data-press-section`, `data-linkhub`.
   - `bandcampUrl` apunta al path `/album/inesperado-contratiempo` (no a la home).
4. Accesibilidad: cada link externo con `rel="noopener noreferrer"`; bloques nuevos con headings semánticos (`<h2>`); contraste AA en el texto nuevo.
5. La página sigue cargando sin layout shift evidente (imágenes con `decoding="async"`, sin width/height dinámicos que reflow).
